応募者対応の流れと採用業務の効率化｜連絡・日程調整・週1回の確認

応募者への連絡や面接日程の調整が後回しになっている、こんなお悩みはありませんか？

  • 社長や総務が現場と兼務で、応募が来ても連絡が翌日、翌々日になってしまう
  • 面接日を決めても、当日に来ない人がいる
  • 今、誰がどこまで進んでいるのか、社内の誰も正確に分からない

地方は仕事を探している人がそもそも少なく、1件の応募を逃すと次がいつ来るか分かりません。そんなときに検討したいのが、応募者対応の流れを決めて、連絡・日程・確認を「仕組み」にすることです。この記事では、採用業務を効率化する手順と、週1回の打ち合わせの回し方が分かります。

応募者対応の流れは？6つの場面に分け、それぞれに「期限」と「担当」を決めます

応募から面接の結果連絡までは、次の6つの場面に分けられます。場面ごとに「いつまでに」「誰が」を決めておくと、忙しい週でも連絡が止まりません。

場面やること期限の目安担当の例
1. 応募が来たお礼と面接日の候補を送る24時間以内総務
2. 返事がない電話かSMSでもう一度連絡する翌日総務
3. 面接日が決まった日時・場所・担当者名を送る返事をもらった当日総務
4. 面接の前日確認の連絡を一言送る前日の夕方まで総務
5. 面接会社と仕事を説明し、話を聞く当日社長・現場の責任者
6. 結果を伝える合否を連絡し、次の日程を決める社内で決めた日数以内総務

期限の目安は一例です。自社の人数や体制に合わせて決めてください。

ポイントは、合否を決める人と、連絡をする人を分けることです。合否は社長や現場の責任者が決めます。それ以外の連絡は、文面と期限を決めて「型」にします。型があれば、担当が不在の日も別の人が代われます。

なぜ連絡の早さで差がつくの？地方の中小企業は、1件の応募の重みが大きいからです

厚生労働省「一般職業紹介状況（令和8年9月分）」では、有効求人倍率は1.19倍、新規求人倍率は2.19倍でした。新規求人倍率は「その月に新しく出た求人の数 ÷ 新しく仕事を探し始めた人の数」です。新しく出る求人の数が、仕事を探し始める人の約2倍あることになります。

中小企業庁の資料（2026年1月「中小企業・小規模事業者の人材に関する現状と課題」）でも、従業員の規模が小さい企業ほど求人倍率が高く、募集しても人を確保しにくいと示されています。さらに「2026年版 中小企業白書」の概要では、中小企業の雇用者数が2040年に2018年の8割半ばまで減る可能性があるとしています。

応募した人は、ほかの会社にも応募しているかもしれません。連絡が遅いと、その間に別の会社で面接が決まることがあります。

よくあるのは、最初の面談を通過した人の多くが、一次面接の前に辞退してしまうケースです。こうした会社では、応募が来た後の連絡の段階で止まっていることが少なくありません。その場合は、次の4つを決めておくと効果的です。

  • 返事から24時間以内に、面接日の候補を出す
  • 面談の前日に確認の連絡を送る
  • 面談の担当者を固定し、話す内容をそろえる
  • 面談の場で、次の面接日まで決める

最初の連絡は何を送る？SMS・電話・2回目の連絡の文例です

SMSの文例（製造スタッフの場合）

〇〇株式会社の△△です。製造スタッフへのご応募ありがとうございます。面接の候補日は ①11月24日（火）10時 ②11月25日（水）14時 ③11月26日（木）10時 です。ご都合の良い番号を返信ください。難しい場合は、ご希望の曜日と時間帯を教えてください。面接は30分ほどです。

候補日は3つ出します。「いつがいいですか？」とだけ聞くと、やりとりが何往復も続きます。

電話の流れ

  1. 会社名と名前を名乗る
  2. 応募のお礼を言う
  3. 「今、2〜3分よろしいですか？」と聞く
  4. 面接の候補日を伝え、その場で決める
  5. 「日時と場所はSMSでもお送りします」と伝える

返事がないときの2回目（翌日）

〇〇株式会社の△△です。昨日ご連絡した面接日の件で、再度ご連絡しました。お仕事中でしたら、ご都合の良い時間にこの番号へ返信いただければ大丈夫です。

連絡は「2回まで（時間帯を変える）」のように回数を決めます。

給与や休日を聞かれたら、求人票と同じ内容で答えます。電話で求人票と違うことを言うと、後のトラブルにつながります。

面接の日程はどう決める？「候補を3つ出す」か「予約の枠を先に作る」かです

方法1：候補を3つ出す（応募が月に数件の会社）

面接できる曜日と時間を「火曜と木曜の10時・14時」のように固定します。毎回社長の予定を聞かずに候補を出せます。

方法2：予約の枠を先に作る（応募が多い会社・面接する人が複数いる会社）

採用管理の仕組みや予約カレンダーの機能を使い、空いている時間に応募者が自分で予約できるようにします。たとえば、システムの設定だけで次のような流れを自動にできます。

  1. 応募者を「書類通過」にする
  2. 予約用のURL入りメールが自動で届く
  3. 応募者が、複数の面接官のうち誰かが空いている時間から選ぶ
  4. 予約と同時に日程が決まり、担当面接官の紹介入りの確定メールが届く

設定した後は、テスト用の応募者を1人作り、10分ほどで「メールが届くか」「空き時間が正しく出るか」「確定メールの面接官が、実際に空いていた人になっているか」を確かめます。

どちらの方法でも、一次面接の場で次の面接日まで決めると、連絡の往復が1回減ります。

面接の前日と当日は、何をする？確認の一言と「来ないとき」の決まりです

前日の確認の文例

明日11月25日（水）14時からの面接、お待ちしています。場所は本社事務所（〇〇市〇〇町）です。駐車場があります。担当は工場長の□□です。ご都合が変わった場合は、この番号へご連絡ください。

一言送るだけで、日時の勘違いや、場所が分からず来られないことを防げます。

当日、時間になっても来ないとき

  • 開始から15分たったら、電話とSMSで1回ずつ連絡する
  • 連絡がつかなければ、その日のうちに「改めて日程を決めることもできます」と送る
  • 応募者一覧に「当日来なかった」と記録する

結果の連絡

合否の連絡は「面接から何日以内」と社内で決めておきます。合格の場合は、その連絡の中で次の日程まで決めます。見送る人にも、必ず結果を伝えます。

「誰が・どこまで進んだか」は、どう管理する？応募者一覧に「今の段階」と「次にやること」を書きます

表計算ソフトで十分です。1行に1人、次の列を作ります。

列書く内容の例
応募日11/20
応募経路ハローワーク／求人サイト／紹介 など（選んで入れる）
今の段階下の7段階から選ぶ
次にやること前日の確認連絡
期限11/24
担当総務

「今の段階」は、次の7段階から選びます。

応募 → 書類通過 → 一次面接 → 一次面接通過 → 最終面接 → 内定 → 内定承諾

入社と辞退は、別の列で数えます。

数字が合わなくならないための決まり

  • 数は「その週に新しく起きた件数」で数える（合計ではない）
  • 月の数は「その出来事が起きた日の月」で数える
  • 応募経路と段階は、手で打たずに一覧から選ぶ（「ハロワ」「ハローワーク」のような書き方の違いを防ぐ）
  • 入力する欄は黄色、計算式の欄は灰色にして「灰色は触らない」と決める

数字がおかしいときは、集計の表ではなく、元の応募者一覧の段階や日付を直します。

毎週の採用の打ち合わせは、どう回す？15分・3つの議題・前日までの入力です

目的は、数字を集めることではなく、次に何をするかを決めることです。数字は前日までに入れておき、当日は見るだけにします。

15分の進め方

  1. 数字のズレとその理由（5分）：今週・先週・今月の合計を見て、目標より多いか少ないか、その理由を話す
  2. 面接待ち・返事待ちの人（5分）：名前を1人ずつ確認し、次の連絡を誰がいつするか決める
  3. 今週やること（5分）：担当と期限を決める

議事メモのひな形

【11月第4週】
数字：応募3（先週5）／面接2／内定0
ズレの理由：求人サイトの応募が減った。原稿を2週間変えていない
返事待ち：Aさん（内定の返事、期限11/27）
今週やること：原稿の写真を差し替える（総務・11/26まで）
終わったこと：ハローワークの求人票の更新（完了）

続けるコツ

  • ズレは、多いときも少ないときも理由まで書く
  • 「理由」の欄だけは、担当者が自分の言葉で書く。ここが一番大事な話し合いの材料になります
  • 終わったことは「完了」として次の週のメモから消す

目標の数の立て方は、採用計画の記事で詳しく扱います。

どこで止まっているかは、どう見分ける？段階ごとの「通過した割合」を見ます

通過した割合は「次の段階に進んだ人数 ÷ 前の段階の人数」で出します。たとえば応募10件のうち一次面接に来た人が4人なら、40％です。

割合が低い段階考えられる理由最初に見直すこと
応募 → 一次面接連絡が遅い、候補日が少ない、前日の確認がない最初の連絡までの時間を1週間記録する
一次面接 → 通過求人票と実際の仕事・条件がずれている求人票を、実際の仕事に合わせて直す
内定 → 承諾内定までに日数がかかる、条件の伝え方が不十分最終面接から内定までの日数を決める

応募経路ごとにも分けて見ます。経路ごとの数が分かると、翌年どこにお金と時間を使うかを決めやすくなります。

応募者対応で、法律と信頼のために気をつけることは？4つの点です

  1. 求人票と違うことを言わない：職業安定法では、求人の情報を正確に示すことが求められています。厚生労働省のリーフレットでは、実際より高い賃金を載せる「虚偽の表示」や、モデル収入例を必ず支払われる基本給のように見せる「誤解を生じさせる表示」をしてはいけないとしています。電話やSMSでの説明も同じです。
  2. 募集のときに示す条件を確かめておく：厚生労働省によると、2024年4月から、募集の際に示す条件に「仕事内容の変更の範囲」「働く場所の変更の範囲」、期間の決まった契約の場合は「更新の上限」などが加わりました。応募者に聞かれたら、すぐ答えられるようにしておきます。
  3. 年齢や性別で連絡の扱いを変えない：年齢や性別を理由に面接に呼ばない、連絡を後回しにする、といったことはしません。電話で家族や出身地を聞くこともしません。
  4. 応募者の情報を見られる人を決める：応募者一覧は採用のためだけに使い、見られる人を限ります。社内のグループ連絡で応募者の名前や電話番号を流さないようにします。

仕組みができたか、何で確かめる？10項目のチェックリストです

  • [ ] 6つの場面ごとに、期限と担当が決まっている
  • [ ] 最初の連絡のSMS文例と電話の流れが、紙かデータで共有されている
  • [ ] 面接できる曜日と時間が決まっている
  • [ ] 候補日を3つ出す（または予約の枠を作る）準備ができている
  • [ ] 面接の前日に確認の連絡を送る担当が決まっている
  • [ ] 当日来ないときの連絡のしかたが決まっている
  • [ ] 応募者一覧に「今の段階」「次にやること」「期限」の列がある
  • [ ] 応募経路と段階は、一覧から選んで入れるようになっている
  • [ ] 週1回15分の打ち合わせの曜日と時間が決まっている
  • [ ] 電話やSMSで伝える条件が、求人票と同じになっている

専任の担当がいない会社は、どこまで外に任せられる？面接と合否は社内に残し、連絡と日程調整を任せます

社長や総務が現場に出ている日は、連絡が遅れがちです。そのときは、連絡と日程調整は外に任せ、面接と合否の判断は社内に残すという分け方があります。

社内でやること任せられること
面接をする求人原稿の作成
合否を決める求人サイトの運用
内定の条件を決める応募者への連絡・日程調整

任せる前には、次の点を確かめておくと安心です。

  • 応募者に送る文面を、事前に見せてもらえるか
  • 応募者一覧（今の段階）を、いつでも見られるか
  • 何にいくらかかるかが、はっきりしているか

費用の考え方は「採用代行の成功報酬型とは？地方の現場採用で損しない費用の考え方」で詳しく説明しています。

Remi Threeの「キマルマデ」は、地方企業専門の採用代行です。求人原稿の作成、Indeedなどの運用（Airワーク等）、応募者への連絡、面接日程の調整を代行し、貴社は面接に集中できます。初期費用・月額固定費は0円で、採用が決まった時だけ採用代行費がかかります（広告費は貴社負担で、媒体への実費です）。応募者の合否はすべて貴社が判断します。AIは事務の効率化に使い、選考の判断には使いません。連絡が追いつかないと感じたら、一度ご相談ください。

よくある質問

Q. 応募者への最初の連絡は、電話とSMSのどちらがいいですか？

両方を使うのがおすすめです。まず電話をかけ、つながらなければSMSで面接の候補日を3つ送ります。電話で決まった場合も、日時と場所をSMSで送ると勘違いを防げます。現場で働く人は日中に電話に出られないことが多いからです。

Q. 夜や休日に来た応募は、どうすればいいですか？

求人サイトの自動返信などで「応募を受け付けました。〇日までにご連絡します」と伝えておきます。そのうえで、次の営業日の午前中に最初の連絡をすると決めておくと、休み明けに連絡が後回しになるのを防げます。連絡する日を約束したら、必ず守ります。

Q. 社長1人で採用している会社でも、週1回の打ち合わせは必要ですか？

1人でも、毎週同じ曜日に15分、応募者一覧を見る時間を取る意味があります。「返事待ちの人」と「今週やること」を書き出すだけで、連絡のもれに気づけます。総務や現場の責任者が1人でも加われば、面接の日程も同じ場で決められます。

Q. 採用管理のシステムを入れないと、効率化はできませんか？

表計算ソフトの応募者一覧で始められます。1行に1人、「今の段階」「次にやること」「期限」の列を作れば、進み具合は見えます。応募が増えて面接する人が複数になったら、予約の自動化ができる仕組みを検討する、という順番で十分です。

Q. 応募者への連絡を外に任せても、合否はうちで決められますか？

キマルマデでは、応募者の合否はすべて企業が判断します。任せるのは求人原稿の作成や求人サイトの運用、応募者への連絡、面接日程の調整です。会社は面接に集中し、誰を採るかは社長や現場の責任者が決めます。

まとめ

応募者対応は「応募→最初の連絡→日程決定→前日の確認→面接→結果連絡」の6つの場面に分け、期限と担当を決めると止まりにくくなります。応募者一覧に「今の段階」と「次にやること」を書き、週1回15分の打ち合わせで理由と次の一手を決めます。手が回らない部分は、合否を社内に残したまま連絡と日程調整を任せる方法もあります。
